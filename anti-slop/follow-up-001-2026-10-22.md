# Follow-up audit 001: panel unit dan sidebar

Pemilik memilih temuan 2/4 dan meminta sidebar desktop yang dapat diciutkan serta sidebar mobile lewat tombol kiri atas. Implementasi ini mencakup permintaan itu; temuan 1 tertangani melalui containment nama di panel baru dan temuan 3 melalui penutupan sidebar setelah navigasi. Temuan 5/6 belum diimplementasikan.

## Hasil

| Bagian | Perilaku akhir | Bukti |
| --- | --- | --- |
| Sidebar desktop | 288px atau 72px ikon; nama menu tetap tersedia melalui accessible label/title | Playwright collapse/expand dan accessible-name assertions |
| Sidebar mobile | Native modal di kiri; opener di header, tutup/Escape/backdrop/navigasi dan resize ke desktop | Pemeriksaan routing, Escape/focus restore, backdrop dan resize |
| Panel unit | 440px kanan, nonmodal/push mulai 1440px; modal dengan backdrop di bawahnya; full width di bawah 640px | Uji 1440/1280/768/390/320px dan screenshot |
| Selection panjang | Tidak ada overflow; nama lengkap tersedia lewat disclosure | Reproduksi nama 300 karakter pada lima ukuran layar |
| Fallback foto | 80px dalam kartu 288px, sekitar 27.8% | Assertion rasio 25-30% pada lima ukuran |
| Tutup panel | Tombol, Escape dan backdrop; pencarian/page tetap, fokus trigger/scroll dipulihkan | Focus trap, close, query dan resize checks |
| Unit nyata | Tabel identity/status memakai service existing, cursor tetap | 83 unit test lulus; live record yang dipilih tidak berisi unit, bukan bukti browser non-empty/cursor |

Palet Figma tidak berubah. Gambar gelap dari pemilik dipakai sebagai acuan komposisi panel, bukan izin mengubah theme atau menambahkan tombol mutasi/history yang belum tersedia.
